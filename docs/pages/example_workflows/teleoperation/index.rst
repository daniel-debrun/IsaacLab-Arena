Teleoperation and Replay
========================

Launch an Arena environment, control the robot with a teleop device, and save
successful demonstrations to an HDF5 dataset. Replay the dataset to inspect the recorded motions.

Each walkthrough follows three steps:

1. **Launch the environment** with zero actions to preview the scene.
2. **Record demonstrations** using your preferred teleoperation device.
3. **Replay demonstrations** in one or more environments.

Choose an environment below. Each page includes its prerequisites, commands, and controls.
